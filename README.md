# Fraud Detection System
This project is a Fraud Detection System built using a Naive Bayes machine learning model to classify messages as fraudulent or non-fraudulent. It is designed to detect different types of fraud, such as Phishing, Identity Theft, Investment Fraud, and more.

# Key Features:
Message Classification: Classifies input messages into categories such as Phishing, Identity Theft, and other types of fraud.
Naive Bayes Model: Trained on a dataset of messages to detect fraudulent patterns.
Flask Web Interface: A simple web interface built with Flask for easy interaction.
# Technologies Used:
Python: For building the machine learning model and backend logic.
Flask: For the web interface.
scikit-learn: For the Naive Bayes model.
pandas: For data manipulation.
HTML/CSS: For creating the front-end interface.
# Dataset:
The model is trained on a dataset of messages, which is kept private and loaded from a secure location (not included in the repository).
